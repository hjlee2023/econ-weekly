# 주간 경제학 서재

경제학 워킹페이퍼 중 그 주에 여러 분야 편집자가 동시에 주목한 것을 골라 한국어 해설과 원문 초록 정독으로 엮은 주간 서재.

**→ https://hjlee2023.github.io/econ-weekly/**

출처는 NEP(New Economics Papers) — RePEc 신착을 분야별 편집자가 손으로 골라 내는 주간 리포트다. 거시·금융·투자 16종에서 후보를 모으고, 여러 분야 편집자가 동시에 고른 논문과 최상위 기관(NBER·CEPR·BIS·IMF·중앙은행) 신착을 가중해 추린다.

|---|---|---|
| 2026-W37 | 9월 2주 · 통화정책과 금융안정 | 6편 |

## 저작권

각 논문 초록의 저작권은 해당 저자·발행기관에 있습니다. 이 사이트는 학습 목적의 인용과 한국어 해설이며, 원문은 각 논문에 달린 RePEc 링크에서 보실 수 있습니다. 게재를 원치 않는 권리자는 [Issues](https://github.com/hjlee2023/econ-weekly/issues)로 알려주시면 해당 항목을 내립니다.

이 저장소에는 빌드 산출물(`index.html`)만 들어 있습니다.
